# DeepEnzyme EMULaToR bench commands

Run from the repo root:

```bash
cd /home/adhil/github/DeepEnzyme
```

## Smoke test on CUDA 2

```bash
CUDA_VISIBLE_DEVICES=2 conda run -n mldb python emulator_bench/run_split_benchmarks.py \
  --split_groups random_splits_grouped_sequence \
  --limit_rows 6 \
  --iteration 1 \
  --seeds 666 \
  --overwrite_prepare \
  --overwrite_features \
  --overwrite_runs
```

Run the same command again without overwrite flags to verify cache reuse and completed-run skipping:

```bash
CUDA_VISIBLE_DEVICES=2 conda run -n mldb python emulator_bench/run_split_benchmarks.py \
  --split_groups random_splits_grouped_sequence \
  --limit_rows 6 \
  --iteration 1 \
  --seeds 666
```

## Full original-settings retraining on CUDA 2

```bash
conda run -n mldb python emulator_bench/run_split_benchmarks.py \
  --gpus 2 \
  --seeds 666 777 888 \
  --runs_per_gpu 6 \
  --cpu_threads_per_run 4 \
  --cpu_interop_threads_per_run 4
```

Run multiple independent split/seed jobs concurrently on CUDA 2:

```bash
conda run -n mldb python emulator_bench/run_split_benchmarks.py \
  --gpus 2 \
  --runs_per_gpu 2 \
  --cpu_threads_per_run 1 \
  --seeds 666 777 888
```

Run across multiple GPUs, with two concurrent jobs per GPU:

```bash
conda run -n mldb python emulator_bench/run_split_benchmarks.py \
  --gpus 0 1 2 3 \
  --runs_per_gpu 2 \
  --cpu_threads_per_run 1 \
  --seeds 666 777 888
```

## Train on original DeepEnzyme log2(value) target instead of EMULaToR log10_value

  --split_groups random_splits_grouped_sequence \
